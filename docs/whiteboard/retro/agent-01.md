**有效的新做法**（最多 3 条）：
1. 发布通过前派独立多路复审，每条回原文或原帧核对；“角色遮挡”类警告看全尺寸帧。何时用：成品已出齐、改动成本是文字时。
2. 改完用旧导出对新页面做文字 diff，差异必须恰好等于计划的改动，再连跑两次生成脚本并逐次看退出码。何时用：改任何“可重复运行”的生成脚本之后。
3. 成片已通过、问题只是修饰性时不重渲，写“下次重渲清单”；真要改一块时只渲该块，用缓存拼整片，没动的段落逐帧（PSNR）和逐采样比旧成片。何时用：视频改动要重走两个口令。
