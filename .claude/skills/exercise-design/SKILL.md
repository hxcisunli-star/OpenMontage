# 课后练习设计

本项目每课的发布包里有一份“课后练习”（`exports/metadata/exercises.txt`，由 `make_exercises.py` 生成，答案来自真实运行）。现有做法的短板：**题目下面紧跟答案**、**没有独立复核题**、“怎么改”和“答案”写在一起，学生很容易直接看答案。

上游方法来自 OpenMAIC 的“习题课（最近发展区）”与“学会学习”（原文见 `references/`；它们讲的页面、代理、`quiz`/`interactive` 页是它自己运行时的东西，本项目没有）。这里只取教学方法。

> 关于“最近发展区”：它是理解发展与协助关系的理论概念；下面的“先独立、再帮助、再独立复核”是教学设计，不是维果茨基提出的固定步骤，也不能从一道题测出学习者的“最近发展区分数”。练习说明里不要写“你正处于最近发展区”。

## 一、先定目标与证据（和 `backward-design` 衔接）
练习只围绕**一个可练习的目标**（例如：看出两个文件放一起会撞名）。先写“学生做完这份练习，能留下什么证据”，再出题。必要的补教服务于这个目标，不扩成新授课。

## 二、每道题标明用途，不把所有题当成同类
| 用途 | 做什么 | 本项目对应 |
|---|---|---|
| 读程序 | 先猜输出再运行 | 练习一 |
| 测零件 | 对一个零件喂固定输入看结果 | 练习二 |
| 找错 | 运行或编译有错的程序，用考卷或报错定位 | 练习三（能运行的错、只编译的错分开写，沿用“不运行未定义行为”） |
| 自己写 | 改规格，先改考卷再改程序 | 练习四 |
| **新题独立复核（新增）** | 不看提示，做一道和前面同难度、表面不同的新任务 | 每份练习至少一道 |

示范题、受助题、复核题要**分别标出**，复核题的结论只写到“这道题独立完成了”，不写“已经掌握这一类”。

## 三、独立尝试在前，答案在后
1. 每道题先让学生**自己写出答案和一句理由**，再去运行核对（现有说明里已有“先在纸上写出你的答案”，保留并加强）。
2. 题面、代码注释、旁边的小字、前一题的示例里**都不能出现本题的答案或改法**。检查办法：把本题答案里的关键值（输出行、diff 行号、改动的那行）逐个在题面与其他题里 `grep`，出现即泄露。
3. “怎么改”的代码片段只放在答案区，且只贴改的那个函数或 case 块（沿用现有约束）。
4. **练习保持一个文件，不拆成“题目”和“答案”两个文件**（用户 2026-10-19 决定）。用每题里一条显眼的分隔（“答案：”单独起行），并在开头写“先做完再看答案”。

## 四、复核题的设计
- 目标动作与前面讲评的一致，**只换数值或表面情境**；
- 不同时引入没讲过的新规则（刚练完正整数，就别用负数或分数当独立复核）；
- 复核之前不讲解这道题；
- 示范题、受助题、复核题的**答案互不相同**，避免套用上一题答案就碰对；
- 若复核失败，答案区要写明“回到哪一道题再做一次”。

## 五、两条路线（要写清具体怎么走）
- 能独立完成且理由充分：直接做复核题；
- 有明确困难：回到对应的找错或测零件题，先做更小的一步（例如先只看报错那一行），再回来。

不要写一个没有实现的“自动分层”或“已掌握解锁”；本项目只有一份文本，路线靠学生自己选，要明说“这是你自己选择”。

## 六、留下记录与间隔复习
练习末尾给四句让学生自己填：
1. 我最初写的答案是……
2. 我借了什么帮助（看了哪句提示、哪段答案）……
3. 换一道新题我自己做的结果是……
4. 我下一步要……

再加一行间隔提示：“过三天，不看答案，把练习三里一个错默写一遍。”并加一题“用自己的话，讲给一个没学过的同学听”（与 `plain-language-review` 衔接）。自报的帮助情况要注明是自报。

## 七、必须保持的本项目约束
- 答案全部来自 `run_exercises.sh` 的真实运行，不手写；每个干净版本 -Werror 干净、-O0/-O2 一致、ASan 无报告；
- 能运行的错只在确定行为的前提下运行；“编译器一个字也不提醒”要写明三套选项都试过；
- 文件只留用到的函数；练习说明里的命令、文件、编译选项与本课一致；
- 简介里对练习的描述与实际一致。

## 完成标准
- 每题有用途标签，至少一道新题独立复核，答案互不相同；
- 泄露检查做过（`grep` 过关键值）；
- 记录与间隔复习提示已写；
- 用 `lesson-fact-check` 过一遍练习里的断言。
