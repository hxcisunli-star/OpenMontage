# 电子书版式规则（2026-11-18 重构起）

视频是热闹的白板，书是摆在旁边的安静讲义。新章、新图都按这里做；样式表 `book.css` 文件头写了同样的四条。

## 颜色：三种，各有一个用途
| 颜色 | 变量 | 只用在 |
|---|---|---|
| 红 | `--red`（标记上的字用 `--red-fg`） | 章的课题大标题、术语词、“实测”标记、提醒的标题 |
| 黄 | `--hl`、`--hl-soft`、`--hl-fg`、`--hl-band`、`--hl-line` | 荧光笔：“想一想”、当前小节和当前视频章节、“示意”标记、“读完你会带走什么”的标题（浅色是压在字下半截的黄带，深色是一道亮黄下划线） |
| 深蓝 | `--accent`、`--accent-soft` | 链接、按钮、“来源说”标记 |

- 用户米色、模型浅青（`--user`、`--model`、`--model-line`，横条的填充用深一档的 `--model-bar`）只出现在图里的对话气泡、格子和横条里。
- 编号、小标签（“故事”、读完带走的 1 2 3）用中性色，不用红。册目录里的章名用黑体粗字，不用手写体；“有正文”“有视频”只是描边小标签。
- 其余一律是中性色：`--fg`（正文）、`--fg-2`（次要）、`--muted`（小字）、`--faint`（小节大号数字）、`--line`、`--line-strong`、`--note-bg`（图里分组的淡底）。
- 规则里不写死颜色值，只用变量；新变量在浅色 `:root` 和两个深色块里都要定义（`@media (prefers-color-scheme: dark)` 里的 `:root:not([data-theme="light"])`，和 `:root[data-theme="dark"]`）。
- 对比度：正文和小字在两套颜色下都不低于 4.5:1，大号数字不低于 3:1。2026-11-18 全部配对实测通过（最低是浅色的“提示标题”4.72）。

## 字体
- 手写体 ZCOOL KuaiLe 只用三处：章的课题大标题（`.lesson-title`）、术语词（`.term .word`）、首页系列名。它没有拉丁字母和数字，含字母数字的标题加 `.latin` 改用黑体。
- 小节标题、图标题、目录一律用系统黑体；等宽体只给代码、时间码和数字。
- 字号阶梯：12、13、14、15、17（正文）、18（故事导语）、20、26，加一个大标题档。

## 一种部件一种样子
| 部件 | 样子 | 不要 |
|---|---|---|
| 故事 `.story` | 大一号的导语段落，上面一个灰色小标签 | 卡片、边框 |
| 来源说 `.fact` | 引文：左边一条细的中性竖线，说法一句，下面两行小字（适用范围、原页）。连着两条以上由模板包进 `.facts`，竖线画在组上，条与条之间一道细线 | 灰底卡、彩色左条 |
| 术语 `.term` | 词条：左边红色手写的词，右边“一句话、类比”，下面一行“哪里不像：…”（标签不重复显示）。连着的由模板包进 `.terms` | 每个词一张卡 |
| 想一想 `.think` | 全页唯一的黄底块，问句在外，答案展开 | 别的部件用黄底 |
| 提示 `.callout` | 淡灰底，标题按种类上色（info 深蓝、tip 绿、warn 红，warn 底是淡红） | 左色条 |
| 图 `figure.show` | 白底、一圈细线、圆角；标题在上；图注在底部一道细线下，标记（实测或示意）在左、口径在右 | 阴影、框里再套框 |
| 代码 | 深色底；在空格和中文处换行，过长的词不从中间折，整块横向滚动 | — |
| 表格 `table.t` | 只有横线，表头下一道粗线 | 竖线、表头底色 |

| 视频抽帧 `.frames` | 一行：一张时放大到 460 像素宽，两三张平分一行，四张以上横向滑；手机上每张占八成宽 | 固定的窄列 |

阴影只给视频、书架上的书、浮层（搜索结果）。

## 章页结构（模板 `build_site.py` 的 `chapter_html` 生成）
1. 页头 `.hero`：左边是位置、课题大标题、大纲标题（`h1`，整站检查要求它等于大纲标题）、基本问题、折叠的“关于这一章”（大纲编号、视频时长、时效、状态标签、先学哪些章）；右边是视频。
2. 通栏 `.take-band`：“读完你会带走什么”，编号清单，两到三列。
3. 两栏 `.layout`：左栏正文 820 像素（段落仍限 38 个字一行，图用满）；右栏 300 像素，从上到下是小窗视频的预留位 `.pip-slot`、视频章节、本章目录（滚动时高亮当前小节）。窄于 1080 像素时变一栏，右栏放到正文前面，本章目录收成折叠。
4. 正文之后：课后练习、下载、“留给下一课的问题”、“附录”（对照大纲、延伸阅读、几个词的大白话、证据抽屉四个折叠）、翻页。
5. 小窗视频由 `book.js` 做：页头的视频滚出屏幕后改成固定定位，盖在 `.pip-slot` 上；只换类名和坐标，不移动视频元素，播放不中断；窄屏和没有脚本时留在原处。

**不能改的钩子**（整站检查、脚本、练习依赖它们；加新类名可以，不要改这些的含义）：`main[data-unit]`、`section.sec#sec-…`、`a.frame[data-seek]`、`q.narr`、`figure.show[data-record]`、`figcaption.rec`、`span.tag-shice/-shiyi/-source/-metaphor`、`aside.fact[data-claim]`、`a.src-link`、`div.term`、`b.word`、`p.gap`、`details.think`（不许 `open`）、`article.exercise[data-ex]`、`div.q`、`details.answer`、`details#evidence`、`details#coverage`、`details#readings`、`#downloads`、`p.lesson-title`、`div.basic`、`div.takeaway`、`nav.chapter-nav`、`nav.crumbs`、`#lesson-video`、`button.seek`、`#progress`、`#q`、`#hits`、`#theme`、`.rd-n`、`li[data-unit]`、`span.chip-path`、`span.chip-st.on/.vid/.off`、`a.book-card[data-units]`、`.bk-t`、`img.cover-art`、占位页的 `div.callout.warn`、`section.lab`。

## 加一种新图
- 外框、标题、图注由 `blocks.show()` 给，新图只写图身。
- 图身里分组用 `--note-bg` 淡底，不再画边框；虚线只给“空位、缺失、示意”这类真有含义的地方。
- 样式放进 `book.css` 的“图”一节，按课分段，手机规则写进文件末尾对应的 `max-width` 块。
- 手机 390 像素不能横向滚动：网格和弹性布局的子项写 `min-width: 0`，长英文词和网址写 `overflow-wrap: anywhere`，宽表格和代码放进自己的横向滚动容器。
- 做完至少看一次：电脑 1280、手机 390、深色各一张全尺寸截图。

## 立体图（2026-11-24 起）
- 选定的图可以“立起来”成立体图（3D），写法和查法全在 `INTERACTIVE.md`：章节 JSON 的 `fig3d` 块、兜底就是原来的静态图、每块积木对回一条记录、算出来的标“示意”。
- 样式在 `book.css` 的“立体图”一节；颜色只取上面的变量（当前一步用荧光黄，按钮和选中项用深蓝），标签是 DOM 文字。
- 新加的钩子（含义不要改）：`div.fig3d[data-scene][data-records][data-refs]`、`.fig3d-head`（默认 `hidden`）、`.fig3d-static`、`script.fig3d-data`、`assets/fig3d.js`（只在有立体图的页面加载）。
- 课后练习的文字支持一小套 Markdown（2026-11-24，交接 l21 §6）：围栏代码（三个或更多反引号，也可以开在一行的末尾）、表格（`|` 开头和结尾的行）、`- ` 列表、`#` 小标题、行内的 `代码` 和 **粗体**；没有这些记号的行原样输出。
