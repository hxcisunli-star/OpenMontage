# 复盘 · 智能体拆拆装装第 9 课《先想一想，再回答，值不值？》（agent-thinking-mode-cn；成片 444.8 秒＋2 秒封面；2026-11-13，全自动托管）
**一句话**：思考模式就是先打草稿、再交答卷；排队题、选数题上两个模型都是关 0／开 10（逐个模型说），找名字题开了只多写草稿；日期题“写了关闭仍有草稿”让学生学会“开没开要看返回”。

**偏离计划之处**：
- 对外调用 256 次，交接时粗估 100–150 次（探测 32、正式 180、流式 32、curl 4、起步脚本演示 8）；演示分项上限 4→8 由复审对话代定，没走 halt；演示里共 5 次调用没留下记录（根因见下）。
- 日期题第二个模型 7/10 开关没按预期，按冻结规则整组不比；第一个模型 2/10，照常比。
- 板书换组叠字、装配图提前装好等在剪辑阶段自查改（D2–D7，scripts/edit_deviations.json）；发布门放行后按复审对话代定做了一次书和练习的文字小修（POST_APPROVAL_CHANGES 第 8–13 条）。
