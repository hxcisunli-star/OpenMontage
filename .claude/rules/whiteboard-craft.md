# 白板课细则（读写课程文件时载入）

完整规则在 `docs/whiteboard/checklists/`（由登记表 `docs/whiteboard/lessons-learned.yaml` 生成）；这里只放写旁白与板书时最常用的几条。

## 旁白
- 无英文字母与阿拉伯数字，数字说汉字；命令、文件名、函数名只写在板上的等宽字体。
- 平均句长 ≤24 字、最长句 ≤50 字，每段 ≤600 字；难词与禁词只存一份 `docs/whiteboard/wordlist.yaml`（检查：`docs/whiteboard_script_lint.py projects/<课程> --allow 本课新词`）；本课新词点名一次并配大白话。
- 时长对账：字数 × 0.238 秒/字 + 三次 3 秒静默 + 段间 0.7 秒；预估低于约 390 秒补“讲清道理”的句子，偏长就删不新增东西的句子。
- 相邻画面提示间隔 ≤10 秒；每个画面事件带旁白锚点，按旁白先后写。
- 引用别课内容前，对那一课的 `script.json` 找原话；计划里的数字要当场数清。

## 板书字形
- 手写体里没有 0、o、c、大写字母和单个拉丁字母：代码、命令、数字、零、终点牌一律用等宽字体。
- 等宽字体里不写中文和全角符号（含“→”）；标签与数值分开写；手写体里不混写拉丁字母与文件名。
- 只出现一段时间的画面都要写 `until`，不要写 `until: None`。
- 每块最后一项笔迹要在淡出前写完（余量 ≥0.6 秒）：`python3 docs/whiteboard_last_item_check.py projects/<课程>`；剪辑阶段首次不过是常态。

## 例子与提醒
- 编译提醒、检查工具报告会随选项、-O 级别、gcc 版本变化：只引本机 gcc 13.3 的原文，写明选项，不下“为什么”；错误例子先在好版本上试会不会真的出这个错。
