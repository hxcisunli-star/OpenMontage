## 复现及证据位置

本机根目录：`/srv/openmontage-render/bench-v5/`。测试程序位于源码 `remote_render/benchmark_v5.py`、`benchmark_capacity.py`、`profile_cpu.py`、`summarize_v5.py`；只允许串行驱动，防止性能样本互相污染。

```bash
sudo -n python3 remote_render/benchmark_v5.py --name NEW-NAME --workers 32 --quota 96
sudo -n python3 remote_render/benchmark_v5.py --name NEW-QUALITY --workers 32 --quota 96 --frames 300 --start 3173 --stills
sudo -n python3 remote_render/benchmark_capacity.py --name NEW-FULL --workers 8 --jobs 4 --frames 11300 --start 0 --quota 96 --balanced --v5-profile
```

测试会修改正式 agent 的 CPU 配额，需协调空闲窗口。测试程序等待队列为空，但不阻止新的生产任务；`foreign_jobs` 非空的性能样本不得作比较。早期曲线未加此自动字段，不冒称有自动排除记录。失败任务保留排障；成功只清理本次测试自己的 job。
