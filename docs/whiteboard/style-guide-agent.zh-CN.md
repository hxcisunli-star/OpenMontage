## 3. 元素样式
- **便利贴**：圆角 5、浅色填充、旋转 ±1–3°、右下偏移 (3,5) 的软阴影；第一行手写体（中文），第二行等宽（代码/英文）。
- **聊天气泡**：圆角 26；用户方 `#E3CA9B`、模型方 `#56CBFD` + 4 px `#093344` 描边；中文用手写体，英文与代码用等宽；气泡下方小字标“用户/模型”。
- **柱状图**：填色块从底线长起；数值用等宽大字放在柱顶；轴标签用手写体；颜色按角色色表。
- **荧光笔与圈注**：荧光笔是黄色 45% 的圆角底，放在字的下面；圈注是红色手绘圈，放在字的上面。
- **场景图卡片**（尚未出样图）：圆角 18、4 px 墨色边框、轻阴影；图里不放字，所有字由合成器叠加。
- **倒计时圆环**（预测题用）：红色圆弧随时间收拢；答案用荧光笔揭晓。第二轮已实现（`ring`，用法见第 7 节）：三段圆弧依次消失。
- **图层顺序（默认）**：填色块/便利贴/卡片/荧光笔底 → 场景插画 → 文字 → 圈注与箭头笔画 → 角色。角色最上层，但只放在不压字的位置。合成器的 `layer:"top"` 字段已提供（E77）。

## 4. 按内容选呈现方式（沿用已批准的计划）
概念比喻 → 彩色插画逐步显现，老师或搭档摆姿势｜流程/传递 → 便条飞行与缩放 + 镜头推近当前步骤｜数据对比 → 填色柱状图 + 大号等宽数字｜代码行为 → 代码 + 旁边的结果面板｜真实界面 → 聊天气泡｜定义 → 便利贴 + 下划线｜常见错误 → 小图上画红叉 + 老师“哎呀”｜预测题 → 彩色题卡 + 倒计时圆环。

## 5. 生成素材的提示词模板（模板与已用提示词在素材库 `prompt_*.txt`，工具 `docs/whiteboard_pose_tool.py`）
- **角色/物件（抠色）**：`彩色平涂卡通插画，简洁的平涂上色，深青黑色细轮廓线，教学插画风格，与参考图同一画风；<主体>；整体完整入画，不要切边；背景是纯绿色（RGB 0,255,0）的单色平涂，没有阴影、没有渐变、没有地面、没有任何文字。` 反向：`渐变背景，阴影，地面，文字，水印，多人，裁切，绿色的衣服，绿色的物体，绿色的反光`。物件本身含绿色时改用品红底，`docs/whiteboard_pose_tool.py` 的抠色支持 `--bg magenta`。
- **改姿势（带参考图）**：`保持图中这位……的外貌、……完全不变，只把姿势改成：……。全身完整入画。背景保持纯绿色单色平涂，没有阴影、没有地面、没有任何文字，只有一个人。`（`image_edit`、1536 档、40 步；参考图用 `teacher_a.png` 或 `robot_c.png`。）
- **场景图**：同一画风，背景简洁浅色，无任何文字；先用远程 Qwen（`text_to_image`，16:9），不够再用 DashScope。
- 旧提示词里“黑色细线、不要彩色”的限制作废；“没有任何文字”保留。

## 6. 文字规则（沿用，不变）

## 7. 第二轮手段与裁定（2026-10-21；用户把去留交给我，按工程与呈现效果裁定）
依据：试点 `projects/agent-messages-v2-cn` 的 s1–s8（同一条旁白）新旧并排关键帧、测得的排版检查 0 错误、整课远程渲染、回测。积木都在 `docs/whiteboard_v2_kit.py`。

**保留**
- **代码上色 + 运行结果面板**（`b.code(…, lang="c" 或 "py")`、`result_panel`）：凡代码板书默认用。配色：关键字 `#9D174D`、类型 `#0B5CAD`、数字 `#92400E`、字符串 `#166534`、注释 `#5B6472`、预处理 `#6D28D9`、函数名 `#0A645D`（纸面上对比度最低 5.77，荧光笔上最低 4.79）；结果面板底 `#EEF2F7`，命令 `#0A645D`、对的结果 `#166534`、错的 `#B91C1C`；浅色面板上的灰字用 `PANEL["title"]` 色。
- **时序图**（`lanes` + `lane_msg`）：程序/模型两列加箭头，讲“调用—回应”时用；标签用等宽，成功的回应绿、失败的红。
- **题卡与倒计时圆环**（`quiz_card` + `ring`）：每道预测题都用。题卡是板上最响的色块（红色“想一想”标签）；圆环的三段圆弧在题目读完后、静默开始前出现，依次消失，最后一段在答案揭晓前 0.4 秒消失。
- **对错分屏 + 对勾红叉**（`split_panels`、`mark_ok`、`mark_bad`）：左对（绿）右错（粉），把“做了/没做”的结果并排摆。
- **红叉 + 老师“哎呀”**（`mark_bad` + 姿势 `teacher_oops.png`）：犯错场景用，每课一两处，不滥用。
- **词元计数条**（`token_meter`）：把“越摞越高、越贵”画成看得见的量；底边要留余量（越线部分会顶到上方标题，试点用 `base_y` 760）。
- **角色微动**（`char(…, idle=True)`）：站立的角色默认开；上下起伏 5 像素、周期 2.6 秒，可调 `idle={"amp": …, "period": …, "sway": …}`；不抢注意。
- **音效**（`docs/whiteboard_sfx.py apply <项目>`）：默认档只开“答案揭晓叮声”（标出“静默结束、现在公布答案”）。pop 与 whoosh 默认关：旁白是主通道、板上又有字，没有信息量的声音是多余材料（多媒体学习的一致性原则）。全量用 `--cues all`，撤销用 `apply --undo`。规则：问答静默里不得有提示点、峰值不高于 −1 dBFS、响度变化不超过 0.3 LU（不满足则不改 props）。流程：build → apply → 渲染（样片与成片都带；音轨在 `audio` 里，不影响板书块缓存）。

**放弃或不进默认**
- **曲线图**（`curve`）：试点没用到、没在课里验证过；函数与回测留在 kit，第一次用要过排版检查并看全尺寸帧。
- **H3 片头**：4.5 秒无声片头加 2 秒封面，开头 6.5 秒没有教学内容，与“每课 2 秒封面”的决定相悖；封面已带两个角色；画面比矢量板书软。
- **H3 比喻片段**：整屏硬切，片段里没有校徽与字幕；板上计数条表达更精确；每个 5 秒约 200 秒生成；试做的片段演“旧便条被挤出”，与那句旁白“越摞越贵、怎么办以后再讲”对不上。
- **H3 工具链**（`docs/whiteboard_h3_clip.py`、`whiteboard_render.py` 的 `video_clip` 块、`whiteboard_prepend_cover.py --sting`）：保留休眠，不进手段清单与场景计划检查；以后做非技术学科、需要真实世界比喻镜头时再评估（登记表 E83）。
