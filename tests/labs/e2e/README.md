# 页内练习真实浏览器测试

在工作区根目录运行：

```bash
node tests/labs/e2e/run_e2e.mjs --site site
```

`--site` 可指定另一份站点，省略时使用工作区的 `site/`。所有测试均在临时副本上执行，原始站点和 `ref/` 保持只读。失败不会阻止后续用例；有失败时进程退出码为 1，每例打印 `PASS/FAIL 名称 耗时`，最后打印汇总。

依赖使用任务书指定的现成环境：Node 18、`openssl`、OpenMontage 虚拟环境的 Python 3.12、Remotion renderer 和 Chrome headless shell。脚本里的绝对路径对应任务书允许读取的位置，不安装依赖、不访问外网。HTTPS 服务使用 `ref/docs/whiteboard/ebook/serve.mjs`，保留其 Basic Auth 和严格 CSP；证书错误仅通过 CDP 忽略。运行结束关闭浏览器与服务器，删除临时站点及认证文件。

自动产物：

- `out/E2E-RESULT.md`：本次运行的各例结果、耗时、覆盖边界和截图清单。
- `out/e2e-results.json`：结构化结果与页面、Worker 的网络、控制台、CSP、未捕获异常诊断；失败页面还记录代码、markers 和 DOM 状态。临时位置和认证会脱敏。
- `out/shots/`：浅色、深色、500 像素窄屏、Python 错误、检查全过、加载错误及各失败页面的 PNG。每次运行先移除旧 PNG，防止使用旧图。

用例拆开执行，页面和草稿互相隔离，每例开始恢复默认配置。刷新恢复草稿的用例保留本例自己的存储。每例总超时 100 秒；等待状态、保存草稿、重置确认过期、提示消失均轮询实际条件，未用固定等待代替完成判定。

| 分组 | 验证内容 |
|---|---|
| A | 开始前零 vendor 请求、两步加载状态、Python 语言与关键字 token、行号、浏览器逐字输入参考答案、三行输出和五项检查、完成标记 |
| B1–B4 | 原始填空代码、全角括号及列号、缩进、除零；真实 markers、仅含学生帧的 traceback；编辑后清标记 |
| C1–C4 | 十秒超时、可继续编辑及 Worker 重建、停止按钮、再次运行、200 行输出截断、`input()` 友好提示 |
| D1–D3 | 500 ms 草稿落盘与刷新恢复、两步重置并清除通过状态、三秒未确认则按钮恢复且代码不变 |
| E1–E2 | 提示依次追加、提示用完与失败两次各自解锁参考按钮、点击后只读纯文本显示 |
| F1–F3 | 500 像素窄屏无运行依赖、文件协议离线、主动阻断 Pyodide 后错误与解除阻断重试 |
| G | 深色初始化和浅色即时切换 |
| H0 | 原版 `set_labs.py --no-yaml` 确实能够切换配置 |
| H1–H2 | 默认允许真实 Ctrl+V、拖放和右键菜单；防线调用及监听器计数都为零，无提示条 |
| H3 | 分别验证 Ctrl+V、编辑命令粘贴、Shift+Insert、拖放、右键菜单的阻断及约两秒提示 |
| H4–H7 | block 下逐字输入、撤销重做、真实 CDP 输入法组词与提交、编辑器复制剪切、输出区选中复制、预览和提示的选择及复制保护 |
| H8–H9 | 不重建切 block 再切 allow；缺失配置、非法 JSON、非布尔字段均恢复允许并实际粘贴 |
| I | 汇总全部页面与 Worker 的控制台错误、CSP、未捕获异常、HTTP/资源失败和站外请求 |
| J | 检查五类截图存在、PNG 格式正确，窄屏截图真实宽度为 500 |

粘贴先授予剪贴板权限、实际写入并读取系统剪贴板确认，然后发送键盘事件；不会用 `setCode` 模拟粘贴。拖放使用真实 CDP `Input.dispatchDragEvent`。逐字输入通过 `Input.insertText`，只用选区和退格移除 Monaco 自动补出的后缀，不修改编辑器选项。

输入法通过真实 `Input.imeSetComposition` 创建组词，再提交文本；没有测试操作系统候选窗内的候选选择，因为无头浏览器没有该窗口。结果不会将这部分称为已测。

提供的站点缺失章内十张截图及一段视频，诊断只对这些精确路径的资源错误作预期标注；F3 主动阻断的 Pyodide 和 H9 主动删除的配置也单独标注。其他错误一律保留，CSP 和未捕获异常不豁免。

当前提供的 `set_labs.py` 在 `--no-yaml` 模式仍导入缺失的 `labs.py`。H0 保留该真实失败；其他 H 用例遇到这个特定导入错误后，用等价配置 JSON 写入继续验证浏览器行为，并在结果中记录。候选修复仅交付到 `out/patches/`，不会被测试入口自动应用。

候选修复的补充验证：

```bash
node --test tests/labs/e2e/test_patches.mjs
```

这会验证 `out/patches/` 中的防线监听范围、允许状态和 dispose 行为，以及 CLI 在缺少 `labs.py` 时的 `--no-yaml` 往返切换；它不会把候选修复应用到被测站点。
