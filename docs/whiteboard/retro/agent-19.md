- 配对格＋两条线的“描述性门槛”：事先写好“分得出／分不出／比不了”的整数判法（4·(sx−sy)≥n 且按题领先至少三道），十四个比较一个都不过线时老老实实讲“这一次量不出”，不为凑差别改题。
