**有效的新做法**：
1. 把现象写成文档交给对方智能体：渲染机连接停顿时，写了一份只含事实和“未验证”标注的说明（无地址与密钥），对方一次回执就定位到直连 SSH 上传停顿、改走代理，并给出 60 次通过的验收。何时用：任何由别的智能体维护的基础设施出故障。
2. 数字绑定原始记录：简介里每个数字从 `validation/real_runs/` 读出并断言，断言一拦到名单对不上就能顺藤摸瓜（E96）。何时用：写简介与练习。
3. 站位按时间量板上的空位再定：`scripts/board_free_space.py` 算出每个时间窗里哪些横向位置站得下机器人而不碰内容，才发现数步子的段落整块板被占满、只能原地蹦（E92）。何时用：角色要上板干活。
